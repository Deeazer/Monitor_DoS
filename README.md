# Монитор доступности портов

Приложение для мониторинга доступности сетевых портов с графическим интерфейсом на PyQt5.

## Описание функционала

### Основные возможности:
- **Мониторинг портов**: Проверка доступности указанных портов на целевом хосте
- **Графическое отображение**: Два типа графиков для визуализации данных
  - График времени отклика (в миллисекундах)
  - График доступности портов (открыт/закрыт)
- **Настройка параметров**:
  - Целевой хост (по умолчанию: localhost)
  - Список портов через запятую (по умолчанию: 80, 443, 8080)
  - Интервал проверки от 1 до 60 секунд
- **Экспорт данных**:
  - Экспорт данных в CSV формат
  - Экспорт графиков в PNG, JPEG, BMP, PDF форматы
- **Управление графиками**:
  - Увеличение/уменьшение масштаба
  - Сброс масштаба
  - Переключение между вкладками графиков
- **Логирование**: Отображение статуса проверки портов в реальном времени

### Интерфейс:
- **Панель инструментов**: Кнопки управления масштабом и экспортом
- **Вкладки графиков**: Отдельные вкладки для времени отклика и доступности
- **Панель управления**: Поля ввода параметров и кнопки управления
- **Лог**: Окно с временными метками всех событий

## Установка зависимостей

### Требования:
- Python 3.7 или выше
- PyQt5
- pyqtgraph

### Установка через pip:
```bash
pip install -r requirements.txt
```

### Ручная установка:
```bash
pip install PyQt5>=5.15.0
pip install pyqtgraph>=0.12.0
```

## Запуск приложения

### Из командной строки:
```bash
python port_monitor.py
```

### Использование:
1. **Настройка параметров**:
   - Введите целевой хост (IP-адрес или доменное имя)
   - Укажите порты для мониторинга через запятую
   - Выберите интервал проверки

2. **Начало мониторинга**:
   - Нажмите кнопку "Начать мониторинг"
   - Наблюдайте за графиками и логом в реальном времени

3. **Остановка мониторинга**:
   - Нажмите кнопку "Остановить мониторинг"
   - Поля ввода снова станут активными

4. **Экспорт данных**:
   - Используйте кнопки экспорта для сохранения результатов
   - Выберите формат и место сохранения

## Особенности

### Технические детали:
- Использует TCP-сокеты для проверки доступности портов
- Таймаут соединения: 1 секунда
- Автоматическое масштабирование графиков
- Поддержка русского языка интерфейса

### Форматы экспорта:
- **CSV**: Данные о времени отклика для каждого порта
- **Изображения**: PNG, JPEG, BMP - визуализация графиков
- **PDF**: Векторное представление графиков для печати

## Системные требования

- **ОС**: Windows, Linux, macOS
- **Python**: 3.7+
- **Память**: Минимальные требования
- **Сеть**: Доступ к целевому хосту для проверки портов
